# Todo Application

A simple task-management application built as a practice project.

## Features

- Create tasks
- View and manage tasks
- Mark work as completed
- Remove tasks
- Practice application state and DOM interactions

## Technology

- HTML5
- CSS3
- JavaScript

## Getting Started

Clone the repository and open the application's main HTML file in a browser, or serve the project with a local development server.

## Purpose

A beginner-friendly project for practicing JavaScript application logic and user interaction.
